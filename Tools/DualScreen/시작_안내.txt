REDBOOL · 두 화면 2인 대전 / v26 개인 동작 보완

Windows 노트북 두 대, Mac과 Windows, Mac 두 대에서 같은 역할 구성을 사용합니다.
Windows는 REDBOOL_v28_Windows.zip을 폴더 전체로 압축 해제합니다.
Mac은 demo_dual_screen_20261112_v28 폴더를 사용합니다.
게임과 카메라는 각자의 노트북에서 실행합니다. 카메라 영상은 다른 노트북으로 전송하지 않습니다.

1. 처음 한 번 설치
Windows: Python 3.11 x64와 Python Launcher가 설치된 상태에서 00_setup_windows.cmd 실행.
인식 라이브러리 설치 파일은 패키지의 windows_wheels에 포함되어 있어 패키지 설치에 인터넷이 필요 없습니다.
Mac: 이 개발 Mac은 기존 Python 환경을 자동 사용합니다. 다른 Mac은 Python 3.11 설치 후 00_setup_mac.command 실행.
07_check_files는 파일과 모델을 확인하며 게임이나 카메라를 켜지 않습니다.

2. 네트워크
두 노트북을 같은 공유기의 유선 LAN에 연결하는 것을 권장합니다. 같은 일반 Wi-Fi도 가능합니다.
격리된 게스트 Wi-Fi는 사용하지 않습니다. 1P 노트북의 로컬 IPv4 주소를 확인합니다.
Windows: 터미널에서 ipconfig. Mac: 시스템 설정 > 네트워크에서 연결 주소 확인.
Windows 방화벽 창이 뜨면 신뢰하는 시연장 사설 네트워크에서 게임의 통신을 허용합니다.
필요한 호스트 수신 포트는 UDP 5065(P1 인식), 5066(P2 인식), 5067(두 번째 게임 화면)입니다.
인터넷 공유기 포트 포워딩은 필요 없습니다.

3. 1P 노트북
01_host_game 실행 → 실제 결투장에 1P·2P 캐릭터가 나타납니다.
02_host_camera 실행 → 카메라 창에서 C → 중앙 가드 보정 → 화면의 수련 동작을 각 2회.
수련에서 검증한 동작 범위로 v26 인식을 개인별 보완합니다. 새 모델을 학습하거나 v26을 교체하는 기능이 아닙니다.

4. 2P 노트북
03_join_game 실행 → 1P 노트북의 IPv4 주소 입력 → 같은 결투장이 나타납니다.
04_join_camera 실행 → 같은 IPv4 주소 확인(이전 주소가 나오면 Enter) → C → 각자 수련.
두 카메라와 두 게임 화면이 연결되고 수련을 마친 뒤 두 사람이 중앙 가드를 1초 유지하면 시작합니다.
1P는 왼쪽 서진(Hero02), 2P는 오른쪽 철문입니다. 기존 게임에 포함된 캐릭터이며 원래 재질 색을 사용합니다. 자기 몸을 화면에서 이동하고 싶은 방향으로 기울입니다.

5. 플레이
왼손 펀치: 잽 / 오른손 펀치: 스트레이트
왼손 레이즈: 하이킥 / 오른손 레이즈: 로우킥
양손 블락: 유지하는 동안 방어 / 몸을 중앙으로 되돌리면 이동 정지
파운장 게이지가 가득 차면 가슴 앞 X자. 사용 후 팔을 풀어 다음 동작을 이어갑니다.
연결이 끊기거나 보정 중이면 두 사람의 전투와 타이머가 멈춥니다.
연결 복구 후 중앙 가드 1초로 재개합니다. 연결이 끊긴 동안의 공격은 나중에 재생되지 않습니다.
라운드 종료 후 1P 게임 창에서 R: 재대전. 같은 사람이면 C나 수련을 다시 할 필요 없습니다.
사람이 바뀌면 해당 사람의 카메라 창에서 C를 눌러 보정과 개인 동작 확인을 다시 진행합니다.
Esc: 메뉴. 카메라 종료: 카메라 창에서 Q.

6. 기존 스토리
05_story_game → 기존 새 게임·이어하기.
06_story_camera → C 보정 후 스토리 플레이.
두 화면 대전은 스토리 진행 기록을 저장하거나 지우지 않습니다.
이전 v26 및 v27 실행 폴더는 그대로 보존되어 있습니다.

주의가 필요한 검증 범위
두 번째 화면은 호스트 상태를 30Hz로 받고 약 50ms 간격을 보완해 부드럽게 표시합니다.
공격 판정은 호스트가 한 번만 계산합니다. 화면 동기화가 카메라 명령의 전송 경로에 중간 단계를 더하지 않습니다.
그렇더라도 네트워크 전송·화면 보완 지연이 0이 되는 것은 아닙니다.
실제 Windows 노트북 두 대에서 방화벽·카메라·화면 지연의 최종 확인은 현장에서 한 번 필요합니다.
Windows 게임은 Unity 설치 없이 실행합니다. Python은 카메라 인식에 사용합니다.
기록은 각 패키지의 play_records에 저장됩니다. 원본 영상은 각 노트북에만 저장됩니다.
