# 지도와 장소별 컷씬

## 화면과 진행
- 지도는 화면 전체를 사용한다. 상단 제목/목표/범례, 하단 설명과 장소별 조작 설명은 표시하지 않는다.
- 메뉴: 왼쪽 위 / 단서 기록: 오른쪽 위 / 전체 지도 보기: 오른쪽 아래.
- 장소명, 연결선, 방문 완료 표식, 현재 위치와 이동 가능 표식은 유지한다.
- 전투 첫 방문에는 대치 장면, 승리 후에는 단서/결과 장면을 재생한다.
- 휴식·조사 장소는 최초 도착 때 재생한다. 휴식 회복량과 1회 사용 규칙은 기존 동작을 따른다.
- 재방문, 지도 다시 열기, 이어하기는 이미 본 장면을 반복하지 않는다.
- 건너뛰기도 감상 완료로 기록하며 대사 전체를 단서 기록에 남긴다. 감상 도중 앱을 종료하면 미완료 장면은 다음 실행 때 다시 재생된다.
- 새 게임과 패배에 따른 진행 초기화 시 감상 이력도 초기화된다.
- 기존 저장은 이미 완료한 장소만 감상 완료로 이관한다. 새 장면은 아직 가지 않은 곳부터 나온다.
- 최종 승리 장면 후 엔딩 크레딧으로 연결한다. 전투 시간이 정지한 상태에서도 대사 연출은 동작한다.

## 아트 연결
`Assets/Resources/Story/Cutscenes`의 에셋을 Inspector에서 수정한다.
- `<장소 ID>_visit`: 첫 도착. 전투 장소는 전투 시작 전.
- `<장소 ID>_after`: 승리 후. 전투 결과나 구출 단서는 이쪽에 둔다.
- Location: 장소 이름.
- Background: 해당 컷씬의 배경 Sprite. 미지정 상태에서는 임시 산수화 배경을 쓴다.
- Lines: 순서대로 나오는 대사. Speaker / Text / Left Portrait / Right Portrait / Speaker On Right.
- 인물 그림이 없으면 그 자리는 표시하지 않는다. 대사별 그림을 지정하여 표정을 교체할 수 있다.
- 왼쪽·오른쪽 인물 영역은 발화자 쪽을 밝게 표시한다.

화면은 전체 화면 컷씬 + 상하 검은 띠 + 이름/대사/글자 출력 + 페이드 구조다.
캐릭터가 실제로 걷거나 싸우는 애니메이션, 카메라 연기, 성우 음성, 튜토리얼 동작 판정은 이번 구조에 포함하지 않는다.
다음 버튼 / Space / Enter로 글자를 즉시 표시하고, 다시 누르면 다음 대사로 진행한다.

## 구현
- StoryCutsceneDefinition: 편집 가능한 장면/대사 데이터.
- StoryCutscene: 지도와 독립된 모달 Canvas, 입력 차단 및 연출.
- RunData.seenStoryIds: 저장되는 감상 이력.
- 단서 기록은 완료 장소 요약과 감상한 장면 대사 전체를 표시한다. 전투 전에는 승리 후 단서를 노출하지 않는다.

## 검증 방법
별도 QA 프로젝트/PlayerPrefs에서 첫 방문, 전투 전후 순서, 건너뛰기, 저장/불러오기, 복귀, 휴식 중복 회복 방지, 기존 저장 이관, 새 게임 초기화, 최종전 종료를 확인한다.
