# Space로 진행하는 프롤로그

새 게임 → 프롤로그 20개 대사/영상 구간 → 지도 → 마른 폭포 동굴 → 벽화 튜토리얼.

- Space 한 번: 현재 대사와 영상을 함께 넘겨 다음 대사/영상 구간으로 이동. 마지막 대사에서는 지도로 이동.
- 전체 건너뛰기 버튼과 Esc 종료는 없음. 대사는 처음부터 전부 표시하며 두 번 누를 필요 없음.
- 입력하지 않으면 현재 대사 유지. 진입 영상이 끝나면 마지막 장면의 무음 왕복 루프를 재생하며 기다림. 공격·발소리 효과음은 루프에서 반복하지 않음.
- 다음 영상의 첫 프레임을 준비하는 동안 이전 화면을 유지. 로딩 중 입력은 쌓지 않아 대사 여러 개가 한꺼번에 넘어가지 않음.
- 모든 대사를 넘긴 뒤에만 seenStoryIds에 완료 기록. 이어하기/지도 재방문은 재생하지 않음. 새 게임은 다시 재생.
- 파일 누락/15초 준비 실패 또는 재생 정체 시 Space 대화로 대체. 재생 중 오류는 현재 대사부터 이어서 표시.
- 단서 기록은 동일한 lines 데이터를 사용. 튜토리얼 완료 상태는 별개.

Assets/StreamingAssets/Cinematics/PrologueSteps 안의 40개 MP4는 자막 없는 진입 영상 20개와 무음 대기 루프 20개. StoryDialogueLine의 videoFileName / holdVideoFileName으로 연결. 기존 Prologue.mp4는 원본 보존용이며 현 프롤로그는 구간 영상을 재생.

Windows Unity 6000.4 영상 정체를 피하도록 skipOnDrop=false 유지. UnscaledGameTime 사용. 두 재생기/RenderTexture를 교대로 사용해 검은 로딩 화면을 줄임. 원화 기반 모션 코믹과 효과음이며 음성 더빙은 없음. 기존 저장을 강제 초기화하지 않으므로 새 게임으로 확인.
