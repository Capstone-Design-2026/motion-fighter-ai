# 필살기 파운장(破雲掌) · 2026-11-04

검은 구름(흑운)을 깨는 손바닥. 기를 오른쪽 옆구리에 모았다가 양 손바닥으로 기파를 밀어낸다.
기존 3D 필살기(동작 없이 1초 정지 + 확정 30 피해, 2D 스프라이트 컷인)를 대체한다.

## 조작 (2026-11-12 즉발로 고정)

| 입력 | 동작 |
|---|---|
| 키보드 `O` 한 번 | 최소 시간(0.35초)만 모으고 바로 발사 |
| 키보드 `I` | 게이지 채우기 (테스트용) |
| 웹캠 가슴 앞 X자 0.7초 유지 (`SPECIAL`) | 바로 발사. 게이지가 없으면 `NOT_CHARGED` |
| 예전 신호 `SPECIAL_CHARGE` | 바로 발사로 받는다. `SPECIAL_RELEASE` 는 무시 |

길게 모아 더 세게 쏘는 기능(최대 2초, 1.5초 완충 시 +20%)은 `SpecialMove.BeginCharge` / `Release` API 로만 남아 있고 입력으로는 쓰지 않는다.
방어 중에 누르면 공격과 같은 규칙으로 방어를 풀고 바로 발동한다.

## 규칙과 수치 (`SpecialMove` 인스펙터에서 조정)

| 항목 | 값 |
|---|---|
| 게이지 | 내 일반 공격이 막히지 않고 맞을 때마다 1칸, 5칸이면 사용. 막힌 공격, 내가 맞거나 막은 타격, 파운장 자체의 적중으로는 차지 않는다 (2026-11-13 변경. 이전에는 맞거나 막을 때마다 1칸). `chargeWhenHit`을 켜면 맞았을 때도 찬다 |
| 정타 피해 | 30, 끝까지(1.5초) 모으면 +20% (최대 36) |
| 방어 시 (기 관통) | 피해의 25% (30 → 8), 유지형 방어도 풀려 버리고 약하게 밀려남(약 0.2m, 뜨지 않음. `SpecialMove.guardKnockback`) |
| 기파 | 초속 12m, 사거리 6.5m, 정타 넉백 (6.5, 1.4) + 경직 0.35초 |
| 끊김 | 발사 전에 맞으면 취소, 게이지 절반 반환 |
| 빗나감 | 기파가 사라진 뒤 0.4초 동안 아무 동작도 못 함 (화면 표시는 없음) |
| 발동 연출 | 0.32초 슬로우(×0.06) + 컷인, 모으는 동안 화면 14% 줌 |

적 AI(`EnemyAI.specialGuardChance`, 기본 0.5): 플레이어가 기를 모으기 시작하면 확률로 0.25~0.6초 뒤 방어를 시작한다. AI 방어는 `guardHoldTime`(기본 1.5초) 뒤 스스로 풀리므로 오래 모으면 먼저 풀린다(심리전).

## 애니메이션

`Unified_Combat.controller`에 `SPECIAL_CHARGE`(반복), `SPECIAL_RELEASE`(0.82초) 상태를 추가했다. 클립은 `Assets/Animation/Combat3D/UnifiedBoxing/Special/`.

- 기 모으기: 무릎을 굽혀 낮추고 상체를 오른쪽으로 감아, 오른쪽 옆구리에서 위아래 손으로 기운 구슬을 감싼다(태극 포구 자세). 구슬이 앞뒤로 구르며 숨 쉬듯 움직인다.
- 발사: 더 감았다가(0.07초) 상체를 정면으로 틀며 양 손바닥을 가슴 높이로 끝까지 뻗는다(0.18초, 기파 출발), 앞발에 체중을 싣고 버틴 뒤 가드로 돌아온다.
- `QiPalmAnimationBaker`가 플레이어 뼈대 위에서 IK로 자세를 잡고(발은 바닥 고정) Humanoid 근육 곡선으로 굽는다. 장갑 모델이라 손목·전완 방향은 근육 값으로 지정했다. 같은 클립을 모든 Humanoid가 재생할 수 있다.

- 적중: 섬광, 충격파 고리 두 겹, 불꽃, 기운 안개, **흩어지는 먹구름**, 순간 조명. 방어 시 작게, 빗나가면 사거리 끝에서 흩어진다.
- 게이지가 차면 두 손에 옅은 기운이 피어오른다.
- 효과음 6종(발동, 모으기 반복, 발사, 적중, 충전 완료, 끊김)은 직접 합성했다(외부 에셋 없음).
- 카메라 줌·흔들림은 `QiCameraFx`가 렌더링 직전에만 더했다가 되돌려, 전투 카메라 계산에 영향을 주지 않는다.
