# 전투 무대 표현 개선

적용 프로젝트: `C:\Unity\VisionStriker`  
작업 시작: 2026-10-20, 검증 종료: 2026-10-21  
범위: 기존 산길 척후병 무대를 제외하고 직전에 추가한 이야기 전투 무대 10곳.

## 변경 내용

- 사각형 돌판을 전투 구역에만 따로 얹는 방식을 제거했다. 기존 180×180m 지형의 표면을 하나로 유지하며, 관문·나루·협곡 입구·요새는 연속된 돌바닥으로, 나머지는 흙/암석으로 구성했다.
- 바닥에 2K 색상·노멀·거칠기 재질을 적용했다. 기존 지형, 게임 충돌 바닥, 캐릭터 동작의 좌표는 유지했다.
- 물은 기존 불투명 줄무늬 셰이더를 교체했다. 연속적인 다중 물결, 프레넬 반사, 주변 반사 프로브, 깊이 기반 굴절과 물가 거품을 사용한다.
- 폭포는 평면 사각형 대신 굴곡이 있는 커튼형 메시, 불규칙한 투명 가장자리, 떨어지는 결, 입자 물보라를 사용한다.
- 계곡 물의 직선 경계가 보이던 문제를 지형 아래까지 수면을 연장하는 방식으로 보정했다. 중복된 유출수 평면을 제거했다.
- 바위 군집, 낮은 풀과 잎, 주변 절벽·소나무를 여러 거리로 배치했다. 나루와 요새에서 물 위에 따로 서던 나무를 제거하고 수목 높이를 실제 지형에 맞췄다.
- 건축 무대에 주변 가옥, 창고·생활 물품, 감시탑을 보강했다. 원형 초가지붕으로 쓰이던 문루는 휘어진 지붕 형태로 교체했다.
- 수문 요새는 수문 양쪽의 옹벽과 암벽을 연결했다. 채석장 입구에 암석과 목재 버팀 구조를 추가했다.
- 야영지의 앞뒤와 옆에 천막·보급품을 추가했다. 기존 천막 천에는 처짐과 굴곡을 넣었다.

자세한 장소별 설명과 실제 화면은 `stage_descriptions.json`, `index.html`에 있다.

## 소품 시안

`Tripo_Concepts`의 이미지는 내장 이미지 생성 도구로 만든 별도 제작용 시안이며, 아직 해당 새 3D 모델이 게임에 적용된 것은 아니다.

1. 불규칙한 바위 둑: 물가/지형 접합부 개선용.
2. 산지 관목: 소나무와 바위 사이를 채우는 용도.
3. 군용 천막: 현재 천막의 디테일을 높일 때 교체하는 선택 소품.

원본 PNG, 제작 안내, 생성 프롬프트를 `Tripo_Concepts.zip`에 묶었다.

현재 개선은 기존 에셋의 반복을 늘리고 재질/연결을 보완한 단계다. 사진으로 만든 초안과 동일한 세밀함을 확보하려면 위 소품처럼 추가적인 형태가 필요하다.
