# 컷씬 음성 재연출 방향

일반 낭독이 아니라 장면 속 상대에게 말하는 연기. 현재 Runway 연결에서 지원하는 목소리와 대사 내부 연기 지시를 사용합니다. 지시를 작성했다는 사실과 실제 생성 결과의 자연스러움은 별도로 검수해야 합니다.

배역: Brodie, 속도: 1.0

## 도윤

40대의 강인한 무인. 가슴에서 울리는 단단한 중저음, 느릿한 노인 말투 아님. 제자에게는 여유와 따뜻함, 적에게는 분노를 억누른 명령. 제자의 위험에서만 한 번 강하게 폭발.

배역: Bernard, 속도: 0.98

## 도윤의 편지

배역: Bernard, 속도: 0.98

## 흑견
