# 기본자세와 짧은 전후 스텝 적용 — 2026-10-19

일반 캐릭터와 산길 척후병에 승인된 SoftHop 기본자세와 ShortStep 전후 스텝을 적용했다.

## 적용 내용

- `UnifiedBoxing/Common`과 `UnifiedBoxing/ScoutContact`의 IDLE, WALK_FORWARD, WALK_BACK 클립 6개를 교체했다. 기존 파일 GUID와 컨트롤러/오버라이드 연결은 보존했다.
- IDLE은 작은 잔발 바운스와 호흡이 들어간 5초 루프다. 실제 플레이에서 골반 높낮이는 약 2.6~2.7cm, 양발이 함께 떨어지는 최대 바닥 간격은 약 1.5~1.9cm다.
- WALK_FORWARD는 앞발부터, WALK_BACK은 뒷발부터 디디고 반대발이 따라온다. 앞발·뒷발 위치가 바뀌지 않는다.
- 움직인 실제 거리를 기준으로 보폭과 재생속도를 계산한다. 벽이나 상대에게 막혀 멈추면 걷기 애니메이션도 멈춘다.
- 이동/기본자세 전환은 0.16초이며, 정지 시 발을 정리하고 작은 바운스로 복귀한다. 공격·방어·피격·KO에서는 이동용 발 고정을 해제한다.
- 물리 충돌의 미세한 바닥 간격을 외형 루트에서 보정했다. 바운스 자체는 클립 내부에 남겨 둔다.

## 이동속도 변경

기존 달리기 수준의 이동속도로 짧은 스텝을 재생하면 지나치게 빠른 발놀림이 되므로, 3D 캐릭터 이동만 기존 설정의 **0.4배**로 조정했다.

- 플레이어: 기존 2.7 → 실제 전진 1.08, 후진 0.864 Unity 단위/초.
- 적: 각 스테이지의 moveSpeed에 같은 0.4배를 적용한다. 적별 상대적인 속도 차이를 유지한다.
- 비전 입력의 이동 강도와 플레이어 후진 배율은 유지한다. 2D 모드에는 이 배율을 적용하지 않는다.
- 공통 조정 지점: `Fighter3DView.BoxingTravelScale`.

## 재생성

`VisionStriker > Animation > Rebuild approved boxing locomotion` 메뉴 또는 `BoxingLocomotionBaker.Batch`로 재생성할 수 있다. `LocomotionReference`에는 보정 전의 기준 자세만 작은 정적 클립으로 보관한다. 생성 결과를 다시 입력으로 삼아 보정이 중첩되지 않는다.

`UnifiedBoxingInstaller`는 이 기준 자세 폴더가 존재하면 승인된 기본자세/전후 스텝을 보존한다. 과거 방식으로 발을 모두 지면에 붙여 바운스를 지우지 않는다.

## 확인

실제 GameScene의 Fighter3DView, Rigidbody2D, 콜라이더, PlayerController, EnemyAI를 사용한 저장하지 않는 검증 장면에서 **121개 검사 통과**.

- 일반 캐릭터/척후병의 기존 컨트롤러 연결, 기본자세의 바운스 높이 및 바닥 접촉.
- 전진·후진·저속 입력·빠른 적·좌우 방향 변경·벽 충돌·라운드 리셋.
- 이동에서 잽·스트레이트·하이킥·로우킥·기본 방어·로우킥 방어·피격·KO로 전환.
- 30/60/120fps에서 발 순서 및 지지하는 발의 고정.
- 실제 비전 이동 함수, EnemyAI 이동, 상대와의 Pushbox 충돌.
- 발 메시 자체의 바닥 관통/들뜸 확인. 이동 중 지지하는 발의 최대 바닥 간격 약 8mm.

검증 도구는 `BoxingStepVerification.Run`이며 `-allBoxingChecks`로 추가 검사를 실행한다. 검증은 열려 있던 장면을 바꾸므로 에디터 작업을 저장한 뒤 별도 배치 실행을 권장한다.

다른 공격/방어/피격/KO 클립과 기존 애니메이션 GUID가 변경되지 않았음을 파일 해시로 확인했다. 이번 요청에서는 Git 커밋/푸시는 하지 않았다.
