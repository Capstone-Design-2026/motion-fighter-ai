# 타격 판정 보정 · 2026-10-27

적용 프로젝트: `C:\Unity\VisionStriker`

## 변경 사항

- Humanoid 전투는 기존 공통 사각형 대신, 애니메이션 뼈를 따라가는 주먹/정강이/발 캡슐을 사용한다.
- 상대의 머리, 가슴, 복부, 양쪽 허벅지/종아리를 별도로 추적한다. 정상 방어 중에는 전완도 가드 접촉 대상으로 사용한다.
- 현재 승인된 모션의 잽은 왼손, 스트레이트는 오른손, 두 킥은 오른쪽 다리다. 기존 클립을 120Hz로 측정해 확인했다.
- 모든 Fighter3DView의 최종 자세 보정(order 100) 뒤, CombatContactWorld(order 150)가 일괄 검사한다. 카메라는 그 뒤(order 200)에 갱신한다.
- 이전/현재 자세 사이의 상대 이동 경로를 검사해 프레임 사이 통과를 줄인다. 활성 구간 밖의 경로는 검사하지 않는다.
- 한 공격은 한 상대에게 한 번만 접촉한다. 첫 접촉에서 무적 상태라 피해를 거절해도, 같은 공격의 회수 중 뒤늦게 피해를 주지 않는다.
- 먼저 맞아 취소된 공격의 아직 처리되지 않은 접촉은 폐기한다. 같은 프레임에서는 계산된 접촉 시각 순서, 동일 시각이면 인스턴스 ID 순서다. 동시 타격 전용 규칙은 추가하지 않았다.
- 접촉한 3D 위치에서 기존 HitVfx를 재생한다. 펀치/킥/가드 소리는 피해가 실제 적용됐을 때 한 번 재생한다.
- 3D EnemyAI의 접근 기준을 최대 1.0 유니티 단위로 줄여 짧은 잽 사거리에서도 전투가 이어지게 했다. 기존 행동 확률/피해량/체력은 유지했다.
- 기존 Rigidbody2D/BoxCollider2D/Pushbox는 이동, 밀어내기, 바닥 충돌에 그대로 사용한다. 애니메이션 파일은 이번 작업에서 수정하지 않았다.

## 유효 타격 구간

공격을 시작한 뒤의 게임 시간이다. 슬로모션/일시정지와 함께 진행된다. 구간에 들어와도 형상이 겹치지 않으면 피해를 주지 않는다.

| 동작 | 시작–끝 | 피격 대상 |
|---|---|---|
| 잽 | 0.120–0.215초 | 머리·가슴·복부 |
| 스트레이트 | 0.295–0.430초 | 머리·가슴·복부 |
| 하이킥 | 0.295–0.490초 | 머리·가슴 |
| 로우킥 | 0.290–0.445초 | 다리 |

머리/몸통 등 부위에 따른 추가 피해 배율은 없다. 현재 공격 피해량은 그대로다.

## 방어 규칙

| 공격 | 일반 방어 | 로우킥 방어 |
|---|---|---|
| 잽 / 스트레이트 | 방어 | 방어 |
| 하이킥 | 방어 | 직격 |
| 로우킥 | 직격 | 방어 |

상대를 바라봐야 방어할 수 있다. 방어 성공 시 기존 상대의 방어 감소율과 가드 반응을 적용한다.

이는 872번의 서로 다른 전투를 뜻하지 않는다. 아래 통제된 공격 144회에 여러 단언 검사 및 별도 상황/흐름 검사를 더한 수치다.

- 7종 Humanoid: 서진, 척후병, 산등성이 정예, 추적자, 수용소 간수, 흑견, 무진.
- 통제된 공격 144회: 네 동작, 좌우 방향, 일반/로우 방어, 멀리서 빗나감, 거리 표본, 적의 새 접근 거리.
- 15/30/60 FPS에 해당하는 프레임 시간 간격 검사. 15/30 조건은 척후병과 무진으로 확인했다. 실제 하드웨어 성능 벤치마크는 아니다.
- 준비 중 이탈, 활성 구간 중 접근, 회수 중 접근, 피격으로 공격 중단, 중복 피해 방지, 뒤를 보고 방어, 일시정지/재개.
- 정지/이동하는 두 캡슐의 프레임 간 접촉 계산과 구간 제한.
- 여섯 상대 모델 배치에서 실제 EnemyAI가 멀리서 접근해 적중. 기존 물리 간격 유지.
- 실제 타격으로 KO 발생: 일반 승리 → 지도/클리어 기록, 패배 → 시작/런 초기화, 최종 승리 → 엔딩 대사/엔딩 화면.
- KO 후 양쪽 조작과 피해 잠금, 슬로모션, 씬 전환 후 시간 복구.
- 검증 전후 원래 `VisionStriker.Run` 저장 문자열 일치 확인.

## 범위와 유지보수

- 이 게임의 이동은 여전히 좌우 전투 평면(XY)이다. 판정도 그 평면으로 투영한다. 카메라 회전 자체가 실제 횡이동을 의미하지 않는다. 향후 캐릭터가 깊이 방향으로 회피하게 되면, CombatContactGeometry를 실제 3D 거리 검사로 확장해야 한다.
- 캡슐은 뼈 위치와 체형을 따라가는 단순화된 형상이다. 옷자락/머리카락/메시의 모든 면을 정밀 충돌시키지는 않는다.
- 매우 낮은 FPS에서 구부러진 실제 애니메이션 경로와 두 프레임을 잇는 보간 경로가 완전히 같다는 보장은 없다. 현재는 15 FPS 조건까지 검증했다.
- 새 애니메이션을 넣거나 재생 속도를 바꾸면 `CombatContactWorld.Window`와 `CombatBodyPose`의 공격 손발을 다시 측정해야 한다.
- Humanoid가 아닌 기존 스프라이트 캐릭터는 원래 사각형 판정 경로를 유지한다. 현재 설치된 7종은 모두 새 판정 사용을 확인했다.
- 기존 Basic Hit 8 프리팹의 빈 루트 머티리얼 경고는 기존 처리대로 해당 렌더러를 비활성화한다. 이번 작업은 그 원본 에셋을 교체하지 않았다.
