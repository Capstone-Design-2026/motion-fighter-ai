# 사부의 행방 — 탐험 지도

## 확인 방법
StartScene에서 새 게임을 시작한다. 기존 저장의 지도는 호환성을 위해 유지된다.
MapScene만 실행하고 진행 중인 판이 없으면 새 이야기 지도를 자동 생성한다.

## 지도 구성
- 마른 폭포 동굴(수련을 마친 출발점) → 척후병 → 청계역
- 계곡 → 관문은 본 경로. 산등성이 → 전망대 → 정자 → 봉화대, 서쪽 다리 → 옛 나루 → 보급 터는 각각 별도 탐색 경로.
- 폐쇄된 관문의 철문 → 약초꾼 쉼터
- 채석장 → 운반 통로는 요새로 진행한다. 동쪽 능선 → 초소 뒷길 → 수용소 → 약품 보관소, 야영지 → 보급 창고 → 수색 움막은 각각 독립된 곁길이다.
- 흑운협 입구의 흑견 → 대피처 → 수문 요새의 무진

총 25지점. 지도 버전 2는 새 게임에서 적용된다. 기존 진행 지도는 자동으로 재배치하지 않는다.
각 노드는 시작 지점을 제외하면 상위 연결이 정확히 하나이며, 서로 갈라진 길은 다시 합쳐지지 않는다.
선택한 가지는 다음 별도 갈림길까지 한 줄로 진행된다. 곁길은 3~4지점을 거쳐 막다른 곳에 도달하며, 단서나 회복을 얻고 기존 갈림길로 되돌아온다.
 직행 경로는 전투 6회이며 다른 전투 가지를 탐색하면 추가된다.
스토리와 단서가 맞도록 현재 지도 연결은 고정되어 있으며, 새 게임마다 무작위로 바뀌지 않는다.

## 입력과 탐험
선택 가능한 노드를 클릭하면 이동 후 바로 처리한다. 전투는 GameScene으로 들어가며 별도 입장 버튼이 없다.
휴식과 조사는 지도 안에서 처리하고 하단에 결과를 보여 준다.
현재 위치에 직접 연결된 지점만 선택 가능하다. 완료 지점도 갈림길을 한 지점씩 거쳐 복귀해야 한다. 여러 지점 자동 이동은 사용하지 않는다.
새로 완료한 지점의 인접 지점이 공개된다. 공개 기록은 복귀와 저장/불러오기 후에도 유지된다.
미발견 노드와 연결선은 생성하지 않고 옅고 농도가 다른 여러 크기의 구름 결로 배경을 덮는다. 배경 산수화는 구름 사이로 비친다. 이름/보스 위치가 미리 노출되지 않는다.
휴식 회복은 각 지점에서 한 번만 적용되며 복귀는 체력을 회복시키지 않는다.
발견한 이야기는 단서 기록에서 다시 읽을 수 있다.

## 범위
이 변경은 지도와 진행 저장, 전투 연결을 구성한다. 벽화 튜토리얼, 납치 컷씬, 새로운 적 모델과 전용 AI는 아직 제작하지 않았다.
전투는 기존 RunConfig의 boss_01~boss_final 설정을 재사용하며 현재 전투 표시 이름만 이야기의 상대에 맞춘다.
기존 엔딩 크레딧으로 연결하며 구출 엔딩 컷씬은 추가하지 않았다.

## 변경 지점
StoryMap.cs: 위치, 연결, 단서와 전투 설정 ID.
RunState.cs: 발견 기록, 안전한 경로 탐색, 복귀와 일회성 이벤트.
MapSceneUI.cs / StoryMapFog.cs: UI, 구름, 캐릭터 표식 이동, 기록 창.
RunConfig.useStoryMap: 새 판에 이야기 지도를 사용할지 설정.
