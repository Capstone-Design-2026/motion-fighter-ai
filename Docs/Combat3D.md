# GameScene 3D 전투 적용

## 구성

- 기존 `Arena3D.unity`의 조선풍 투기장 환경을 `GameScene`에 배치했습니다. 원본 Arena3D 씬은 유지됩니다.
- 양쪽 파이터에 `Boxer_Character` 모델과 Humanoid 애니메이션을 적용했습니다. 상대 전용 모델은 아직 없으므로 같은 모델을 색상으로 구분합니다.
- 렌더링은 3D이며, 이동과 전투 판정은 기존 XY 평면의 Rigidbody2D / Collider2D를 사용하는 2.5D 방식입니다. 깊이 방향 자유 이동은 하지 않습니다. 원근 카메라가 두 파이터를 따라갑니다.
- HP, 가드, 120초 타이머, 지도 진행, 승리 후 지도 복귀, 패배 후 진행 초기화, 양쪽 벽을 유지합니다.
- 원본 Boxer 데모 프리팹/컨트롤러/애니메이션은 수정하지 않았습니다. 씬의 모델에서 데모 키 입력과 데모 타이밍 보정 컴포넌트만 제거했습니다.

## 애니메이션

`Assets/Animation/Combat3D/Boxer_Combat.controller`가 실제 3D 모델을 제어합니다.

- 원본 제공 동작: IDLE, JAB, CROSS, HIGHKICK, LOWKICK 및 네 가지 GUARD 상태.
- 보조 생성 동작: WALK_FORWARD, WALK_BACK, CROUCH, JUMP, HURT, KO.
- 보조 동작은 기본 가드 자세에서 생성한 임시 Humanoid 애니메이션입니다. 전용 모션을 제작하면 해당 상태의 Motion만 교체할 수 있습니다.
- `Combat_Flags.controller`는 기존 전투 코드의 자세 파라미터만 보관합니다. 스프라이트 애니메이션을 표시하지 않습니다.
- `Fighter3DView`가 공격 시작, 피격, 가드 유지, 사망, 방향 회전을 모델에 전달합니다.
- 공격 주기: 잽 0.50초, 스트레이트 0.62초, 하이킥 0.80초, 로우킥 0.72초. 판정은 원본 데모에 정의된 타격 진행률(27/32/31/33%)에 맞춥니다. 네 가지 공격은 기존 공격력 수치를 사용합니다.
- 애니메이션의 Root Motion은 꺼져 있으며 실제 이동·넉백·점프는 게임 로직이 담당합니다.

## 테스트 키와 비전 입력

| 키 | 동작 | UDP action |
| --- | --- | --- |
| A / D | 좌우 이동 | movement LEFT / RIGHT + movement_strength |
| W | 점프 | JUMP |
| S | 앉기 | CROUCH |
| U | 막기 유지 | BLOCK / CROUCH_BLOCK |
| J | 잽 | JAB |
| K | 스트레이트 | STRAIGHT / CROSS |
| L | 하이킥 | HIGH_KICK / HIGHKICK |
| H | 로우킥 | LOW_KICK / LOWKICK |
| P | 기존 상황별 공격 | ATTACK |
| O / I | 기존 필살기 / 테스트 게이지 충전 | 기존 방식 유지 |

기존 P는 서 있을 때 스트레이트, 앉았을 때 로우킥, 공중일 때 하이킥을 실행합니다.
UDP 포트는 동작 5055입니다(옛 웹캠 JPEG 화면 5056은 2026-11-14에 뺐다. 지금 카메라 화면은 게임 안 카메라 패널이 보여 준다). 공격은 동일 동작의 반복 패킷으로 연속 발동하지 않으며 NONE/IDLE 또는 다른 동작 이후 다시 입력할 수 있습니다. 패킷이 1초간 없으면 외부 이동·방어를 해제합니다.
이번 작업은 Unity의 수신 처리를 확장한 것이며 Python 인식 모델 자체를 수정하거나 재학습한 것은 아닙니다.

## 변경 경계

- 기존 2D 스프라이트 표시를 끄고 3D 자식을 연결했습니다. 기존 에셋은 삭제하지 않았습니다.
- 기존 필살기 게이지/컷인 기능은 유지됩니다. 3D 전용 필살기 연출은 이번 범위에 포함하지 않습니다.
- 기존 스테이지의 이름·HP·공격력·AI 수치는 유지됩니다. 스테이지 색상은 3D 모델에도 전달됩니다.
- 이후 다른 보스 프리팹을 추가할 때는 Health / Fighter / EnemyAI / Rigidbody2D / Collider2D / Pushbox와 Fighter3DView 구성을 함께 유지해야 합니다.

## 검증

별도 Unity 프로젝트에서 실제 플레이 모드로 두 Humanoid 모델, 네 공격의 애니메이션/HP 감소, 서서막기/하단막기, 전후진/앉기/점프, UDP 잽/어깨 이동과 연결 단절 시 정지, 양쪽 파이터 순서 유지, 왼쪽 벽, KO, 지도 진입 HP 유지, 승리 복귀와 패배 초기화를 검사했습니다. 실물 카메라의 자세 인식 정확도는 이 테스트에 포함하지 않습니다.
