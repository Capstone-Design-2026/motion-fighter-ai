# 지도 물 흐름 / 움직이는 안개 / 영역 공개

2026-10-14. StoryMap의 25지점·11전투·경로·저장 포맷을 변경하지 않는 시각 개선.

- JourneyWorldMap의 원본 그림 위에 `LivingWater`를 별도 RawImage로 추가. 같은 artwork의 자식으로 스크롤·확대·비율을 공유한다.
- 물 분리는 런타임 셰이더에서 청록 계열 색상 마스크로 수행한다. 원본 PNG를 자르거나 다시 생성하지 않는다. 강·저수지·폭포의 물 색 영역에 작은 UV 흐름과 잔물결을 합성한다. 양쪽 샘플이 모두 물일 때만 합성하여 다리·지형의 흔들림을 억제한다. 이는 그림 기반 연출이며 3D 유체 시뮬레이션이 아니다. 배경 그림이 바뀌면 물 마스크와 방향을 재조정해야 한다.
- `StoryMapFog.Configure`는 기존 clearedNodeIds/discoveredNodeIds로 공개 범위를 다시 만든다. 발견만 한 지점은 작은 주변만, 완료한 지점은 가까운 장소를 기준으로 나눈 넓은 땅과 다음 발견 지점 86%까지의 접근 구간을 밝힌다. 부드러운 경계로 이어져 원형 구멍만 남지 않는다.
- 아직 완료하지 않은 갈림길은 여전히 가려지며 숨겨진 지점은 UI 객체를 만들지 않는다. 전체 지도 보기 또한 이동 권한을 바꾸지 않는다.
- 완료 기록이 늘면 공개 범위는 줄지 않는다. 모든 지점을 완료하거나 run.finished이면 전체 탐험 안개가 사라진다. 그 위에는 풍경용 아주 옅은 장식 구름만 남는다.
- 구름은 밝은 회백색을 유지하고 3가지 크기의 노이즈가 서로 다른 방향과 속도로 이동한다. GPU에서 움직임을 계산하며, 기존처럼 매 0.12초마다 지도의 정점과 노이즈를 CPU에서 재계산하지 않는다. 공개 메시만 지도 재구성 때 만든다.
- 물·구름 모두 unscaledTime 사용, raycastTarget=false, RectMask2D/Stencil 지원. 메뉴·단서 기록·전체지도·드래그·줌 입력을 가로채지 않는다.
- Resources에 셰이더를 넣어 실행 파일에서도 포함되도록 한다. 동적 Material은 해당 UI가 제거될 때 정리한다.
