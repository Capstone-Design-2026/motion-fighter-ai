# 산길 척후병 · 이동에 반응하는 자동 전투 카메라

2026-10-17 · C:\Unity\VisionStriker · ScoutPass

## 전투 중 동작

- 두 캐릭터의 중심을 따라가며, 전투 중심이 무대의 왼쪽/오른쪽으로 이동하면 측면에서 최대 ±14°까지 자연스럽게 회전한다.
- 각도는 위치에 따라 계산한다. 정지 중 계속 도는 연출은 없다. 캐릭터의 숨쉬기·잔발 애니메이션은 카메라 흔들림에 영향을 주지 않는다.
- 중심 주변 0.2m는 회전 변화가 없는 영역이다. 이후 이동 1m당 3.2°로 각도를 바꾸며, 반응을 부드럽게 보간한다.
- 가까이 붙어 싸울 때 최소 거리는 5.4m이다. 거리가 벌어지거나 화면이 좁아지면 두 캐릭터의 머리·발끝과 여백을 고려해 물러난다. 평상시 FOV는 유지한다.
- 상대 위치로 대치 방향을 계산하며, 좌우 순서가 바뀌거나 겹쳐도 시점이 갑자기 180° 뒤집히지 않도록 한다.
- 우클릭으로 무대를 살펴본 뒤 조작 없이 2.5초가 지나면 자동 구도로 부드럽게 복귀한다. Home은 기다림 없이 복귀를 시작한다.
- 일시정지·KO·필살기 연출 중에는 추적이 카메라 연출을 덮어쓰지 않는다. 일반 타격의 히트스톱에서는 캐릭터와 같은 시간 흐름으로 추적한다.
- 화면 좌우 입력 보정, 카메라의 소품 충돌 회피, 전투장 벽은 유지한다.

## 적용 범위

ScoutPass의 360도 무대에 적용했다. 다른 전투 씬은 기존 카메라 설정을 유지한다. 현재 게임의 좌우 이동과 2D 타격 판정은 유지했으며, 철권처럼 캐릭터가 무대 안쪽/바깥쪽으로 횡이동하는 전투는 이번 변경에 포함되지 않는다. 카메라의 자동 회전이 캐릭터를 실제로 횡이동시키지는 않는다.
