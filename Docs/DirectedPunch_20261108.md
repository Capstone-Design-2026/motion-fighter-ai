## 펀치 보완

안쪽으로 뻗는 한 팔이 2D X자 후보에 잠시 걸려 펀치가 차단되는 구간이 있었다. 펴진 팔꿈치와 접힌 X자를 구분하고, 아직 발동하지 않은 잘못된 X자 후보를 해제한다. 이미 발동한 필살기의 중복 방지와 가림 뒤 유지 시간 초기화는 유지한다.

카메라 방향으로 팔을 펴는 동작은 팔꿈치 펴짐, 보정 대비 깊이 변화, 반대 손의 접힌 자세를 함께 확인해 레이즈/블락과 구분한다. 화면에서 수직으로 보이는 모든 손 움직임을 펀치로 허용하지 않는다. 한 팔이 반대쪽 가드 손을 가릴 때 양손 펀치로 잘못 처리하지 않도록 접힌 반대 손을 제외한다.

같은 개발 촬영의 사후 재생에서 LEFT_PUNCH 7→9, RIGHT_PUNCH 5 유지, LEFT_RAISE 9/RIGHT_RAISE 4/SPECIAL 4 유지. 129.107초 중앙 방향 잽과 162.812초 카메라 방향 잽을 복구했다. 다른 잽 1개는 요청 시각이 173.080→172.746초로 이동했다. 새 두 요청은 실시간 Unity 실행 성공으로 검증된 것이 아니다.

수정 검사는 123개 통과. 실제 중앙 잽/깊이 펀치, 좌우 반전 합성 재생, 잘못된 반대 손 동시 공격 방지, 수련·블락·4개 X자 보존을 포함한다. 반전 재생은 새 사람의 오른손 정확도 측정이 아니다.

남은 한계: 153초 무렵 오른손 펀치는 손목이 화면 밖으로 나가 추적 불가였다. 160~166초의 위쪽 펀치 일부는 여전히 블락/복귀 상태와 겹쳐 누락된다. 전체 시도 정답표가 없어 일반화 인식률을 계산하지 않는다. 자연스러운 중앙 잽·스트레이트는 새 실제 플레이로 양쪽을 확인해야 한다.

## Unity 성능 보완

LegCheckBalance가 LateUpdate에서 Animator.bodyPosition을 읽어 기존 전투 로그에 경고 6,109회가 발생했다. OnAnimatorIK에서 값을 기록하고 LateUpdate는 같은 프레임의 기록값과 최종 뼈 위치로 계산하도록 수정했다. 전투 Play Mode 검사 18개가 통과했고 해당 경고는 검사 로그에서 0회였다. 모든 스테이지의 시각적 자세 품질을 검증한 것은 아니다.

RedboolFrameMetrics는 로컬 Player.log에 10초마다 씬 이름, FPS, 프레임 시간 p95/최댓값을 남긴다. 프레임 측정은 unscaled 시간이라 필살기 연출/일시정지 중에도 계속된다. 별도 네트워크 전송이나 카메라 촬영을 시작하지 않는다.
