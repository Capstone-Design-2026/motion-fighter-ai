# 컷씬 음성 — 캐릭터 연기 재제작 V2

2026-10-16 사용자 피드백에 따라 현재 컷씬 38개, 103줄을 Runway에서 모두 재생성했습니다. 자막 내용은 V1과 동일합니다.

배역별 성격과 장면별 감정은 StoryVoiceDirectionV2.md에, 실제 전송한 연기 태그 포함 프롬프트는 StoryVoiceManifest.json에 기록했습니다. 긴 배역 설명은 제작 기준이며, 생성기에 보내는 연기 지시는 spokenText 필드입니다. 메타데이터의 rationale이 음성을 제어한다고 간주하지 않습니다.

서진은 담백한 청년에서 차분한 결의로, 도윤은 여유 있는 무인에서 제자를 지킬 때의 강한 명령으로, 흑견은 낮고 냉정한 압박으로, 무진은 오만한 확신으로 구분했습니다. 조연과 병사도 각자의 목적에 따라 다르게 연출했습니다.

모든 줄을 동일한 음량으로 정규화하지 않고 목소리별 기준 이득을 적용해 조용한 말과 외침의 차이를 보존합니다. 끝 음절 보호용 무음 0.25초를 추가했습니다. 새 WAV에서 30Hz 입 움직임 데이터를 다시 계산했습니다. Unity 임포터에서 빌드용 Vorbis 압축을 유지합니다.

Space로 대사를 넘기는 동작과 영상 진입→반복 구간의 음성 유지 동작은 기존 구조를 그대로 사용합니다. 입 연출은 여전히 음량 기반 2D이며 정밀한 발음별 립싱크가 아닙니다.

최종 발음·감정의 자연스러움은 비교 페이지에서 확인해야 합니다. 자동 연결 검사는 사람의 청취 검수를 대신하지 않습니다. 이전 WAV는 Documents/VisionStriker_Voices_20261016/Audio에, 이전 컷씬·문서는 PerformanceV2/Before에 남겼습니다.
