# 흑운협 지도·컷씬 작업

- 물 흐름은 최초 설정의 2배. 직전 1.69배에서 약 18.3% 증가.
- 영상은 준비가 끝난 원본의 너비·높이·픽셀 비율을 읽어 출력 크기를 정한다.
- 영상과 대화 UI는 1920×1080 기준 화면을 창 안에 균일하게 맞춘다. 16:9, 16:10, 21:9, 4:3에서 화면이 잘리거나 인물이 늘어나지 않도록 바깥 여백을 둔다.
- 프롤로그 영상의 이야기와 장면은 유지한다. Space로 다음 대사와 영상으로 전환하며, 기다리는 동안 다음 이야기로 자동 진행하지 않는다.
- 지도 대화 37개와 프롤로그 대체 대화에 16명 인물을 연결한다: 적 11명, 서진, 도윤, 연화, 약초꾼, 의원.
- 적은 기존 11명 초안을 참고해 대화용 배경 없는 그림으로 파생 제작했다. 전투 모델·애니메이션은 변경하지 않는다.
- 서진과 도윤은 기존 프롤로그 그림을 참고한 대화용 그림을 사용한다. 이름이 ‘주인공’으로 남아 있던 대사 표시는 ‘서진’으로 통일한다.
- 동굴은 기존 동굴 그림, 나머지 대화는 지도에서 해당 장소 주변을 보여준다. 배경은 천천히 이동하고 대화 인물은 호흡·고개·손·턱이 작게 움직인다.
- 입 주변 움직임은 글자 표시와 짧은 대사 읽기 시간에 맞춘 2D 그림 변형이다. 음성에 맞춘 발음별 립싱크나 3D 캐릭터 연기는 아니다. 마스크 인물은 입을 움직이지 않는다.
- 처음 방문만 컷씬 표시, 단서 기록, 기존 진행 데이터와 엔딩 연결은 기존 구조를 유지한다. 실제 사용자 저장 데이터는 수정하지 않았다.

## 추가 보완 제안

지도 효과는 현재 정도에서 멈추고 실제 플레이 화면에서 가독성과 피로도를 확인하는 것이 좋다. 다음 우선순위는 장소별 환경음, 주요 대사의 음성, 중요한 대사에서의 표정·별도 포즈다. 장편 영상 전체를 다시 만드는 것보다 몇 장면에 힘을 주는 편이 효과적이다.

## 확인 자료

`index.html`: 실제 Unity 컷씬 캡처와 움직임 미리보기.
`validation.txt`: 별도 테스트 프로젝트 검증 결과.
`cast_manifest.json`: 컷씬별 연결 인물 목록.
`Backup`: 적용 전 원본.

이미지는 내장 image_gen 도구로 제작했으며, 출처·요청 문구는 `image_provenance.json`에 기록한다.
