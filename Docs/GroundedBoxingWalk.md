# 걷기 접지 보정 · 2026-10-17

> **2026-11-13**: 적의 걷기는 이제 기본값으로 이 방식(코드가 발을 IK로 놓기)을 쓰지 않는다. 주인공 스텝을 옮긴 걷기 클립이 발을 직접 딛는다(`Fighter3DView.authoredSteps`, `Docs/EnemyHeroMotion.md`의 "걷기 구조"). 이 문서는 `authoredSteps`를 껐을 때의 동작이다.
>
> 다만 사람이 조종하는 캐릭터(`PlayerController`)는 지금도 이 방식으로 걷는다. 주인공은 모든 모드에서(주인공 이동 방식이 `RunConfig.heroMovement = CommonWalk`라 승인 스텝 `HERO_*_STEP`은 쓰이지 않는다), PvP에서는 고른 12명 모두 이 방식이다.

## 2026-11-16 좌우로 걸을 때 발이 뜨는 문제

증상: 모든 캐릭터가 좌우로 걸을 때 발이 바닥에서 뜬 것처럼 보였다.

### 잰 것

`Assets/Editor/FootGroundingProbe.cs`로 12명(주인공 + 스토리 상대 11명)을 스토리 전투(실제 스토리 길로 연 무대, 상대는 EnemyAI와 같은 빠르기)와 PvP(지하 동굴 투기장, 1P를 복제한 2P, 왼쪽·오른쪽 자리)에서 앞·뒤로 걸렸다. 60fps로 프레임마다 그 자세의 스킨 메시를 구워서, 발 뼈에 붙은 정점 중 가장 낮은 점의 높이를 2D 바닥 높이와 견줬다.

- 스토리 상대(걷기 클립이 직접 딛는다): 거의 바닥에 붙어 있었다. 흑견만 두 발이 모두 1cm 넘게 뜬 프레임이 26~30%(최대 1.1cm), 옥졸장이 최대 1.0cm.
- 사람이 조종하는 캐릭터(IK 걷기): 적 11명의 몸으로 PvP를 하면 딛는 발이 1~3cm 떠 있었다. 앞으로 걸을 때 두 발이 모두 1cm 넘게 뜬 프레임이 최대 55%(철문·무진·능선 정예병·산길 척후병). 골반은 걸음마다 최대 12cm 오르내렸고, 드는 발은 6~7.6cm까지 올라갔다. 주인공은 딛는 발은 붙어 있었지만 골반 6cm, 드는 발 4.8cm.
- 딛은 발이 옆으로 미끄러지는 것은 어디서나 초당 1.4cm 이하라 원인이 아니었다. PvP의 2P가 주인공 전용 스텝 상태(`HERO_*_STEP`)가 없는 적 컨트롤러를 쓰는 것도 지금 설정(CommonWalk)에서는 쓰이지 않아 원인이 아니었다.

### 원인

1. IK가 발 치수를 잴 때 발끝 방향을 주인공 뼈대에 맞춘 고정 기울기(약 -11.6도)로 돌렸다. 다른 11명의 뼈대에서는 발이 앞으로 숙여져(까치발처럼) 발바닥 두께가 실제와 -1.0~+3.7cm 다르게 잡혔고, IK가 딛는 발을 그만큼 띄워 놓았다.
2. 착지한 발이 한 걸음 내내 몸 뒤로 끌려서 뒷발이 골반에서 멀어질 때마다 다리가 닿도록 골반을 크게 내렸다. 걸음마다 몸이 출렁였다.
3. 드는 발을 4~6cm 들어 올렸다.

### 고친 것 (겉모습만)

- `GroundedBoxingWalk`
  - 발끝 방향은 수평으로만 돌리고, 기울기는 기본자세 그대로 둔다(모든 캐릭터의 기본자세는 발바닥이 바닥에 평평하다).
  - 기본자세 메시에서 신발 아랫부분 정점을 발(발가락 앞쪽은 발가락) 뼈 기준으로 뽑아 두고(`LowestSoleY`), 매 프레임 실제 자세(발목 기울기, 클립의 발가락 꺾임 포함)에서 가장 낮은 점이 바닥에 오도록 발목 목표를 정한다.
  - 착지 위치를 반 걸음 앞으로 옮겨 몸이 딛은 발 위를 지나가게 했다. 걷기 시작의 첫 걸음은 짧게(0.6배) 내딛는다. 골반은 다리가 필요할 때 바로 내리고 천천히(초당 20cm) 올린다.
  - 드는 발 높이를 줄였다(바닥에서 약 3cm).
- `Fighter3DView`
  - 걷기·스텝 상태에서 두 발바닥 중 낮은 쪽이 바닥 위 0~4mm 안에 오도록 모델 전체를 위아래로 맞춘다(최대 ±4cm). 스토리 상대의 클립 걷기에도 적용된다. 기본자세로 돌아가면 0.1초, 공격·막기·피격·KO·필살기가 시작되면 0.05초 만에 풀린다.
  - 발 치수는 기본자세가 자리 잡은 프레임에 한 번 잰다(클립으로 걷는 적도 재야 위 보정을 쓸 수 있다).

바꾸지 않은 것: 이동 속도, 판정, 피해, 공격 시각, 충돌, 걷기 클립과 주인공 승인 클립.

일반 캐릭터와 산길 척후병의 걷기를 실제 전투 이동량에 연결했다. 기존 V4 상체 가드와 공격·방어·피격·KO 클립은 유지했다.

## 바뀐 동작

- 실제 프레임 사이의 위치 변화로 이동 여부와 속도를 계산한다. 입력을 누르고 있어도 벽이나 상대에게 막히면 제자리 걷기를 멈춘다.
- 이동 속도에 따라 보폭과 발을 교대하는 간격을 조절한다. 출발 중 속도가 변할 때도 현재 발걸음 시간을 다시 맞춘다.
- 지지하는 발을 월드 좌표에 고정하고, 다른 발이 낮은 궤적으로 앞으로 또는 뒤로 이동한다. 무릎과 골반 높이를 함께 보정해 다리 길이를 넘지 않게 한다.
- 실제 2D 바닥을 조회해 접지 높이를 계산한다. 모델을 처음 연결할 때 맨발/신발의 메시와 다리 길이를 각각 측정한다.
- 정지하면 발을 순서대로 기본자세로 모은다. 공격·두 종류 방어·피격·KO가 시작되면 약 0.09초 동안 걷기 보정을 해제한다.
- 척후병처럼 런타임에 모델을 교체해도 같은 보정을 자동으로 다시 연결한다. 라운드 초기화와 큰 위치 변경 시 이전 발 고정 위치를 폐기한다.

이동 속도, 전투 판정, 피해량, 공격 타이밍은 바꾸지 않았다. 새 애니메이션 파일을 중복 생성하지 않고 공유 보정 코드를 추가했다. 현재 평평한 전투 바닥을 대상으로 하며, 계단·경사면 보행을 새로 만든 것은 아니다.
