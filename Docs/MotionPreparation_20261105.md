# 모션 자동 연결과 전투 준비

전투 씬 로드 후 `PlayerController`와 `Fighter`가 있으면 새 수신기와 준비 제어기를 자동 구성한다. 기존 수신기가 있으면 재사용하며 같은 포트의 중복 수신기는 비활성화한다. 기존 5055 수신기는 새 수신기가 활성화된 동안 비활성화된다. 개별 씬을 수동 수정할 필요가 없다. 메뉴·지도는 그대로이고 튜토리얼은 기존 자체 수신기를 사용한다.

## 실제 플레이

1. Unity 6000.4.5f1로 전투 씬을 열고 Play를 누른다. 카메라 연결 전에는 양쪽 캐릭터와 라운드 시간이 대기한다.
2. 최신 Python으로 `bash scripts/run_seated_demo.command --host 127.0.0.1 --movement --seconds 600` 실행.
3. 카메라 창에 포커스를 두고 C로 앉은 가드 자세를 보정한다. 중앙 가드 준비 자세를 2초 연속 유지하면 전투가 시작된다.
4. 정상적인 공격·블락·이동 때는 준비 단계로 되돌아가지 않는다. C로 재보정하거나 X로 인식을 중단하면 즉시 대기한다. 연결 또는 유효 추적이 0.5초 이상 끊기면 대기하고 복귀 시 다시 2초 준비한다. 입력 만료에 따른 이동 해제는 기존 150ms 규칙을 유지한다.
5. Python 종료 시 STOPPED를 받아 대기한다. 같은 Python 실행으로 다음 전투 씬에 들어가도 새 수신기와 동기화 후 준비한다.

준비 잠금은 KO/스토리의 `InputLocked`와 별개다. 기존 KO·피격·방어 후딜을 우회하지 않는다. 준비 잠금 진입 시 진행 중 공격·방어/예약 입력을 취소하고 피해를 차단한다. 시간 배율을 전역으로 변경하지 않으며 라운드 카운트다운만 보류한다. 잠깐의 추적 손실은 입력 만료로 처리하고 지속 손실에만 전투 준비를 재시작한다.

## Python 호환성과 연결 검사

STATE에 `calibration_version: 1`, `calibrated: true/false`를 추가했다. ACK에 `calibration_contract: 1`, `battle_preparing`을 추가한다. 기존 프로토콜/수신기 버전과 공격 유효기간은 유지한다. 이 두 필드가 없는 예전 Python으로는 새 전투 준비 잠금을 해제할 수 없으므로 Python 수정도 함께 받아야 한다.

`tracking=SYNTHETIC`인 최신 probe는 연결 검사 모드로 플레이어만 해제한다. 적과 라운드 시간은 계속 대기하고 상대 피해도 막아 검사 중 KO를 피한다. 이후 실제 카메라로 전환하면 별도로 2초 준비한다. 이는 실제 적중/피해 검사가 아니다.

## 검증

- 순수 C# 준비 상태 검사 19개 통과: 미보정, 중립 유지, 정상 공격, 짧은/지속 추적 손실, 재보정, 단절, 오래된 시간 간격, 검사→카메라 전환, 종료.
- Python 회귀 89개 통과: 실제 live 발행기를 모의 프레임으로 실행해 보정 false→true→X false→STOPPED가 전송됨을 확인. 실제 카메라는 열지 않았다.
- Editor 메뉴 `Tools > REDBOOL > Run Input Adapter Self Check`에도 같은 준비 검사를 포함했다.
- Play 중 `Tools > REDBOOL > Check Battle Auto Connection (Play Mode)`로 수신기 1개·플레이어 연결·예전 수신기 비활성화·준비 잠금을 확인할 수 있다.
- 실제 Unity 임포트/Play 검증은 별도다. 전투 씬 진입, 보정 전 적·타이머 정지, 준비 후 정상 전투, X/C/Q, 추적 손실/재연결, KO 후 잠금 유지, 튜토리얼→다음 전투까지 확인한다. 합성 연결 검사 통과는 실제 모션 인식률·화면 지연·적중 검증을 대신하지 않는다.

## 필살기 후보 — 아직 미배정

가슴 앞에서 양팔을 X자로 교차해 약 0.7초 유지하는 동작을 우선 후보로 제안한다. 얼굴 앞 블락과 높이를 구분하고, 양팔 교차와 유지 시간을 함께 판정한다. 게이지 충족 때만 유효하며 후보 진입 시 일반 공격과의 충돌을 제어하고 복귀 전 중복 발동을 막아야 한다. 손목 겹침/가림과 사용 편의는 실제 짧은 촬영으로 비교 후 확정한다. 현재 모델·수신기에 필살기를 임의 배정하지 않았다.
