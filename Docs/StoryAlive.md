# 동굴 수련과 단서 조사 연출

- 동굴 컷씬의 중복 backgroundTexture 필드를 정리하고 기존 TrainingCaveMurals 그림을 연결했습니다. 벽화 장면에서는 인물 그림을 숨깁니다.
- 수련은 2.6초 시범 → 기본 자세 확인 → 동작 두 번 성공 → 다음 단계입니다. 잽/스트레이트/하이킥/로우킥/막기/좌우 어깨 이동 총 7단계입니다.
- 오인식 안내, 12초 이상 진행이 없을 때 동작별 팁, 시범 다시 보기, 키보드 테스트, 중단 후 단계 재개를 지원합니다.
- 낮은 신뢰도와 NaN, 같은 자세를 유지한 반복 입력, 어깨 이동 신호 누락은 성공으로 처리하지 않습니다. 기존 ATTACK만 보내는 백엔드는 네 공격을 구분할 수 없으므로 안내합니다.
- 현재 패킷만으로 실제 추적 유효성을 확정할 수 없습니다. 실제 카메라 인식 품질은 별도 사용자 테스트가 필요합니다.
- 28개 대사에서 벽화/서류/흔적/매듭/수로 도면을 확대해 보여줍니다. 조사 컷은 접근 줌과 느린 시선 이동, 부유 먼지를 사용합니다.
- 일반 대화에는 손·고개·호흡·옷자락 변형과 대사 전환 시 진입 동작을 더했습니다. 음소 립싱크나 3D 관절 애니메이션이 아닌 2D 연출입니다.
- 첫 방문 기록, 단서 기록, 지도 경로와 전투 진행은 유지합니다. 이미 완료한 수련 세이브는 초기화하지 않습니다.
- 기존 오프닝 영상은 유지합니다.

검증: 분리된 Unity 프로젝트에서 37컷씬 83대사, 7가지 영상 샘플, 튜토리얼 24개 검사 및 실제 loopback UDP 수신 통과.
새 삽화 4개는 내장 이미지 생성 도구로 제작했습니다. 원본과 프롬프트는 StoryAliveImageProvenance.json에 기록했습니다.
