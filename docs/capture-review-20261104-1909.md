## Unity 연결 단계

촬영 자체의 Unity ACK는 0회로, 이 촬영은 캐릭터 실행 확인이 아닙니다. 카메라 없이 연결 검사로 네 공격 기술명, 호환 수신기, 시간제 방어 시작/종료를 먼저 확인합니다. 연결 검사가 실제 게임에 입력을 보내므로 전투 씬이 Play 상태일 때 진행합니다.

```bash
bash scripts/check_unity_connection.command --host <Unity-PC-IP>
bash scripts/run_seated_demo.command --host <Unity-PC-IP> --movement --seconds 600
```

두 번째 명령은 사용자가 직접 실행하며 카메라 영상을 로컬에 저장합니다. 실행 후 편한 가드에서 C로 보정하고, 첫 확인은 네 공격을 각각 한 번씩 천천히 수행합니다. 블락, 좌우 이동·중앙 정지를 확인한 뒤 2~3분 연속 플레이를 진행합니다. 테스트 종료는 Q입니다.

실제 화면에서 공격 시작과 적중은 구분합니다. APPLIED는 입력 적용이며 적중 보장이 아닙니다. GAME_BUSY는 게임의 동작/피격 후딜 중 거절입니다. 거절된 공격은 뒤늦게 재생하지 않습니다. 이동 방향·정지·연결 종료 시 해제와 실제 체감 지연은 게임 화면으로 확인해야 합니다.
