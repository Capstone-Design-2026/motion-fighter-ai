# 모션 블락 유지와 펀치/레이즈 구분 — 2026-11-09

카메라 블락은 자세를 유지하는 동안 계속 막고, 자세를 풀면 해제한다. Python의 기존 120ms 해제 대기를 제거했다. Unity Fighter의 카메라 전용 소유권을 통해 정해진 방어 시간 및 방어 실패 0.5초 후딜을 적용하지 않는다. 방어에 성공해도 사용자가 자세를 유지하면 계속 막는다. 일반 AI/키보드의 기존 시전형 방어 규칙은 유지한다. 피격·KO·공격 후딜 등 다른 동작 제한은 해제하지 않는다. STATE 해제를 다음 공격보다 먼저 처리하고, 통신 만료/정지/보정 해제 시에는 카메라 방어를 푼다.

수신기 ACK의 guard_mode는 held_pose_immediate_release이다. Python probe는 3초 동안 블락이 유지되는지도 확인하므로 최신 Unity와 함께 사용한다. 기존 receiver_version은 호환상 유지한다.

펀치/레이즈: 높은 정면 펀치가 화면에서 위쪽 이동으로 보이는 경우, 강하게 펴진 팔꿈치와 깊이 방향 증거를 함께 사용해 구분한다. 최대 100ms의 깊이 추정 흔들림은 현재도 유효한 관절이 펴져 있을 때만 펀치 경로로 유지한다. 공격을 예약하거나 지연 실행하는 기능이 아니다. 다른 팔의 굽힌 자세, 높이 제한, 기존 회수/중복 방지 조건을 유지한다.

촬영 20261109_000249_f1751532 재생: LEFT_PUNCH 13→15, RIGHT_PUNCH 18 유지, LEFT_RAISE 12→11, RIGHT_RAISE 6 유지, SPECIAL 3 유지. 225.094초 정면 펀치가 LEFT_RAISE에서 LEFT_PUNCH로 교정됐고, 166.026초 대각선 펀치가 복구됐다. 확인한 굽힌 레이즈와 휴식 구간은 보존됐다. 개발에 사용한 기록의 재생이며 독립 인식률이나 새 버전의 실제 게임 성공률은 아니다.

검증: Python 134개 통과, Unity 실제 Fighter 검사 21개 통과. 새 Mac 앱에 UDP로 네 공격과 3초 방어 유지/해제 시험 통과. 상태 전송 중단 300ms 후 방어가 해제되는 것도 확인했다. Mac 16씬 빌드 오류 0, 기존 경고 50.
