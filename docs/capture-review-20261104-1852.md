# 18:52 새 촬영 확인 — 2026-11-04

이번 촬영은 v7 수정 뒤 새로 수행한 자료입니다. 이 확인 중 인식 기준이나 학습 가중치는 변경하지 않았습니다. 결론은 **가드 복귀는 확인됐지만, 왼손 레이즈 5회 무누락 통과로 판정할 수는 없음**입니다.

## 실제 영상과 로그

- 5개 동작 안내를 완료했고 실제 손 올리기는 재시도 포함 7회였습니다. 6회 인식, 1회 누락입니다. 발생한 6개 이벤트는 실제 서로 다른 손 올리기에 대응하며 중복 발동은 아닙니다.
- 두 번째 안내에서 2회 올렸고 둘 다 인식됐습니다. 세 번째 안내에서도 2회 올렸으나 첫 시도가 누락됐고, 가드 복귀 뒤 재시도는 인식됐습니다.
- 누락된 시도는 PREPARE에서 시작했습니다. 키보드에 손을 내렸다가 가드에 충분히 멈추기 전에 손을 올려, 레이즈 채널이 준비되지 않은 상태였습니다. 약 2470~2600 프레임의 실제 손 올리기를 영상에서 확인했습니다. 2620 프레임에 가드 준비가 회복되고 다음 시도는 2646에서 인식됐습니다. 늦게 하나의 동작이 발동한 것이 아니라 복귀 후 별도의 재시도입니다.
- GO 이후 실제로 수행한 두 시도는 둘 다 인식됐습니다. 나머지는 GO 전 PREPARE에서 수행됐습니다. 이것을 안내 구간만으로 2/5 또는 성공 안내만으로 5/5라고 계산하지 않습니다.
- 실제 동작 후 가드 복귀는 7/7, 초기·동작 후·휴식 후 GUARD 안내 내 READY는 7/7입니다.
- 약 4.67초의 REST 안내 동안 공격·블락·이동·READY 출력은 없었습니다. 권장한 10초 전체의 휴식 검증은 아닙니다. 촬영 전체에서도 원치 않는 블락/이동은 없었습니다.
- 처리한 4,004프레임 모두 영상 RGB 해시·관절 시간 대응을 확인했습니다. 저장 오류는 없습니다. 카메라 4,010프레임 중 처리 슬롯 건너뜀 5프레임과 종료 시 미처리 1프레임이 있어, 전체 카메라 프레임이 모두 저장됐다는 뜻은 아닙니다.
- 실제 처리 시각으로 재생하면 6개 이벤트의 종류와 프레임이 라이브 로그와 정확히 일치합니다. 촬영 시각만으로 재생하면 2개 이벤트가 한 프레임 뒤에 발생하지만 사건 수와 종류는 같습니다.

## 안내 보완

PREPARE에 다음 동작명이 함께 표시되어 손을 먼저 올릴 여지가 있었습니다. 준비 화면에서는 동작명을 숨기고 **WAIT: RETURN BOTH HANDS TO GUARD / HOLD GUARD STILL**만 주황색으로 표시합니다. 준비가 확인된 뒤에만 녹색 **GO: YOUR LEFT HAND UP**이 나옵니다. GUARD/REST에는 GO를 붙이지 않습니다. 인식 성공 여부와 관계없이 원본과 안내 구간을 저장하는 방식은 유지합니다.

인식 기준을 완화해 준비되지 않은 상태를 억지로 성공으로 만들지는 않았습니다. 손을 계속 든 채 가드 복귀 없이 공격을 반복하도록 변경하지 않았습니다. 수정은 안내 화면에 한정됩니다.
