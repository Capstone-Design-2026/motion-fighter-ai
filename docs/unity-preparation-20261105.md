# 2026-11-07 v9: X자 필살기와 동작 연결 보완

현재 기본은 Lite + seated-flow-cross-20261107-v9다. Unity UDP 규약과 기존 수신기는 바뀌지 않았다.

## 조작 변경

- C로 최초 보정하고 Python을 계속 켜 두면 다음 전투에서도 보정값을 유지한다.
- 레이즈 후 양손을 정확한 가드 위치로 돌릴 필요가 없다. 각 손을 내렸는지 따로 판정하고, 다른 손 기술로 연결할 수 있다.
- 펀치는 해당 팔을 몸 가까운 굽힌 자세로 회수하면 다시 준비한다. 펼친 팔을 계속 유지하거나 시간만 지났다고 재발동하지 않는다.
- X자는 가슴~턱 아래 높이에서 양팔을 교차해 유지한다. 이전의 낮은 가슴 높이만 허용하던 조건을 보완했다. 양쪽 어깨·팔꿈치·손목이 화면 안에 보여야 한다.
- 양손이 중앙으로 모이는 단계부터 X자 후보가 입력을 소유해 일반 펀치가 먼저 나오지 않게 한다. 확인된 X자 시간 0.7초가 필요하고 짧은 기하 판정 흔들림은 시간을 더하지 않고 보류한다. 관절 누락/긴 프레임 단절은 유지 시간을 초기화한다.
- X자를 유지하면 1회만 요청한다. 팔을 분리한 자세가 확인되면 다음 동작으로 넘어갈 수 있으며, 꼭 보정 가드 자세일 필요는 없다.
- BLOCK 후 한쪽 손만 내리고 다른 손을 계속 들고 있어도 그것을 새 킥으로 만들지 않는다. 새 레이즈는 해당 손의 내려감이 먼저 확인되어야 한다.
- 카메라 창 X 키는 인식 일시정지/보정 해제, Q는 종료다. 몸으로 만드는 X자와 다르다.
- 가드 복귀 제한 완화와 Unity 후딜은 별개다. 피격·공격 후딜·KO 등에는 GAME_BUSY가 올 수 있다. 거절된 공격을 나중에 몰아서 실행하지 않는다.

2026-11-07 21:17 촬영을 원본 관절·촬영 시각·C 보정 순서대로 재생했다. 기존 SPECIAL 0건에서 13건으로 증가했고, 198.64초 X자 진입에서 나오던 펀치 입력은 사라졌다. 영상으로 확인한 마지막 X자 5회는 각 1회 인식했다. 이 세션은 수정에 사용한 개발 자료이므로 독립 검증 정확도나 새 촬영 성공률이 아니다.

기존 펀치·레이즈·블락·이동·가드 복귀 기록, 중복 방지·가림·통신·보정 검사를 포함한 104개 검사가 통과했다. 새 실제 X자 회귀 3개도 통과했다. 중간 가드 없는 좌우 레이즈, X자→레이즈→X자, 편한 한손 회수, 유지 중 중복 방지를 포함한다. 기존 19:09 왼손 레이즈 5회도 보존됐다.
