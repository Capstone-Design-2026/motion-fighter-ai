# Seated vision demo v5

앉은 자세의 Mac 내장 카메라 입력을 Unity UDP 5065 수신기로 전달합니다.
잽·스트레이트·왼손 레이즈 하이킥·오른손 레이즈 로우킥·블락과 상체 좌우 기울이기를 지원합니다.
이 데모는 학습 모델의 분류 결과를 쓰지 않고 관절 변화와 상태 규칙을 사용합니다. 모델 재학습은 이 변경에 포함하지 않습니다.

## 실행

저장소 루트에서 기존 README의 Python 3.11 `.venv`와 requirements를 준비하고 MediaPipe Lite 파일을 `pose_landmarker.task`에 둡니다.
이 모델과 촬영 파일은 Git에 포함하지 않습니다. 기존 프로젝트 환경을 사용하면 다시 설치할 필요가 없습니다.

```bash
bash scripts/run_seated_demo.command --check
bash scripts/run_six_gesture_check.command --movement
```

첫 명령은 카메라/UDP를 열지 않습니다. 두 번째 명령은 시작부터 원본 영상·관절·로그를 로컬에 저장합니다.
카메라 창을 선택하고 영문 입력 상태에서 C를 누른 뒤, 중앙에서 편한 가드를 2초 유지합니다.
YOUR LEFT/RIGHT는 자신의 왼쪽/오른쪽입니다. GUARD에서 손을 C 보정 당시 높이로 되돌립니다.
NONE/REST는 손을 편하게 내리고 중앙에서 쉬는 상태입니다. GUARD 및 양손을 더 높이는 BLOCK과 구분합니다.
상체 이동은 의자를 고정하고 좌우로 기울입니다. 몸통 회전이나 머리만 기울이기를 입력으로 사용하지 않습니다.
M은 이동 켜기/끄기, X는 일시정지, Q는 종료입니다. 검사 중 C로 재보정하면 안내가 중단됩니다.

Unity 연결기는 짝이 되는 **Unity vision demo v5** PR을 적용합니다. 팀원 PC에서 테스트할 전투 씬에 새 수신기를 설치하고 Play를 누릅니다.
아래 IP는 실제 Unity PC의 사설 IPv4로 바꿉니다. 같은 PC에서만 127.0.0.1을 사용합니다.

```bash
bash scripts/check_unity_connection.command --host 192.168.0.10
bash scripts/run_seated_demo.command --host 192.168.0.10 --movement --seconds 600
```

최신 Unity 방어는 기본 1.5초 동안 유지되는 게임 규칙입니다. 손을 내려도 진행 중인 방어를 바로 취소하지 않습니다.
새 연결기는 한 자세당 방어 1회만 시작합니다. 바쁜 게임에서 거절한 공격은 나중에 재생하지 않습니다.
`GAME_BUSY`를 모션 인식 누락과 구분합니다. 연결 검사 성공은 실제 타격 성공이나 화면 지연 검증을 의미하지 않습니다.

## 변경 및 검증

- 자연스러운 가드 복귀에서 추정 팔꿈치 깊이 변화가 잠금을 풀지 못하던 문제를 보완했습니다. 각도 절대 상한, 2D 각도, 손 위치·속도, 복귀 유지 시간을 함께 검사합니다.
- 미발동 펀치 후보로 시작된 위쪽 동작을 레이즈로 전환합니다. 이미 발동한 펀치는 실제 복귀가 필요합니다.
- 한 손 레이즈의 반대 손 높이 변화와 양손 블락을 구분합니다.
- 두 팔과 레이즈 복귀가 모두 완료돼야 READY입니다. 어깨 추적이 끊기면 이동을 즉시 해제합니다.

개발에 사용한 두 촬영에서 이전 촬영의 펀치6/6·레이즈6/6·복귀18/18이 유지됐습니다.
최신 촬영은 펀치6/6 유지, 실제 레이즈4/6→6/6, 동작 뒤 복귀17/21→21/21입니다. 이동·정지6/6도 유지됐습니다.
휴식 후 처음과 다른 높이의 마지막 자세는 READY로 강제 인정하지 않습니다. C 보정 자세로 돌아오거나 새로 보정해야 합니다.
이 결과는 개발용 재생 결과이며 독립 촬영이나 다른 참가자의 일반 인식률을 보장하지 않습니다.

47개 Python 검사는 로컬의 비공개 촬영 자료를 읽기 전용으로 사용해 통과했습니다. 해당 영상은 업로드하지 않습니다.
테스트 자료 경로는 `REDBOOL_DEMO_SESSION`(이전 펀치 촬영), `REDBOOL_GUARD_SESSION`(14:04), `REDBOOL_LATEST_SESSION`(14:39) 환경변수로 지정합니다.
자료가 없으면 해당 검사들은 skip되므로 skip을 인식 검증 성공으로 해석하지 않습니다.

```bash
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
```

공유 런타임 의존성도 함께 포함했습니다. 기존 V1 실행 경로와 학습 모델은 바꾸지 않습니다.
다음 확인은 독립 촬영 1회, Unity 컴파일·Play Mode, 짧은 연속 플레이입니다.
여러 참가자·거리·조명에 대한 모델 학습은 실제 동작 구간을 검토한 추가 데이터와 참가자/세션 분리 평가 후 진행해야 합니다.
