# 오른손 스트레이트 보완 / 바로 결투 시험

## 판정 변경

v13은 충분히 가로로 뻗은 팔의 2D 팔꿈치 각도도 증거로 사용한다. 단안 깊이 추정이 흔들릴 때 3D 각도 하나만으로 펀치를 취소하지 않는다. 2D 팔꿈치 2.2 rad 이상, 보정 대비 .7 rad 이상 펴짐, 어깨 너비 기준 이동 .50 이상, 수직 비율 .65 이하, 기준점 바깥 방향 운동, 내려찍기가 아닌 조건을 함께 요구한다. 기존 양손 가드/X 소유권, 관절 유효성, 같은 팔 회수 및 중복 방지는 유지한다. 좌우에 같은 규칙을 적용하며 모델 재학습은 아니다. Lite를 유지한다.

## 23:32 촬영 재생 비교

20261108_233220_6ea7a9c0의 실제 촬영 시각과 보정 마커를 재생했다. RIGHT_PUNCH 9→23, LEFT_PUNCH 9, LEFT_RAISE 5, RIGHT_RAISE 8, SPECIAL 1. 영상에서 확인한 오른손 펀치 15구간을 회복했고, 기존 139.085초 입력 1건은 사라졌다. 이 구간은 양손을 든 뒤 이어지는 오른팔 동작으로, 전환 구간 누락은 남는다. 카메라 정면으로 짧게 뻗거나 높이 뻗은 일부 동작도 여전히 빠진다. 이 수치는 개발 데이터 재생 이벤트 수이며, 전체 시도 대비 정확도 또는 수정 후 실제 게임 성공 횟수가 아니다.

실제 촬영에서는 수련 7단계 14회 성공 로그, 카메라 29.96fps, capture→engine p50/p95 15.19/21.20ms, 전투 steady windows 약59.4~59.8fps. APPLIED 20, GAME_BUSY 2, TUTORIAL_APPLIED 10. 게임 프레임은 씬 전환이나 지도에서 더 낮아질 수 있다.

## 바로 결투

Unity PR #7의 새 실행 파일에 --redbool-duel-test 인자를 주거나 시작 화면의 ‘바로 결투 · 테스트’를 선택한다. GameScene으로 바로 들어가며 캠페인 저장/삭제를 막고 저장된 체력/진행을 적용하지 않는다. F5로 전투 도중에도 즉시 다시 시작한다. 카메라는 계속 켜 두면 보정값이 유지되며 새 전투는 새 유효 상태가 도착해야 시작한다. 일반 게임은 인자 없이 실행한다. 테스트에서 일반 진행으로 돌아가려면 앱을 종료하고 일반 게임으로 실행한다.

Mac: demo_release_20261108_duel/02_direct_duel_test.command → 01_start_camera.command. C로 한 번 보정, 왼손/오른손 펀치를 번갈아 시험하고 오른손은 자연스러운 정면/대각선 방향을 비교한다. I를 여러 번 눌러 충전 후 X자와 후속 레이즈도 확인한다. F5가 화면 밝기 키로 동작하면 fn+F5. 마지막 카메라 창 Q로 기록 종료.
