v30 개인 보정과 v26 유지 범위 (2026-11-12)

기본 SixGestureEngine, X자 판정, 복귀, 가드 해제, 입력 유효기간은 그대로다.
--personal-calibration으로 실행할 때만 수련 단계의 좌표 기반 표본을 모은다.
별도 신경망 재학습이 아니다. 매 참가자의 C 보정과 같은 세션의 수련으로 범위/속도를 제한적으로 맞춘다.

수정
1. 펀치의 기하학적 시작을 기억한다. Unity가 두 번째 성공을 인정해 RETURN으로 먼저 바뀌어도 이미 시작한 동작의 최고점/복귀를 끝까지 측정한다.
2. 펀치 팔꿈치 펴짐의 표본 기준을 v26의 기존 기준과 맞춘다. 모션 표본은 최소 3개 유효 관측(그중 최고점 조건 2개), 0.06~4초의 동작, 150ms 복귀를 요구한다.
3. X자는 v26이 요구하는 실제 팔 분리 후 복귀가 확인되면 표본을 마친다. 양손을 강제로 원래 가드까지 옮기지 않아도 된다. X 인식 기준/700ms 유지 조건은 바꾸지 않는다.
4. 일관된 두 펀치 표본에서는 해당 손의 시작 속도를 0.80~0.65 범위로만 조정할 수 있다. 일관성 없는 동작/한 표본/극도로 작은 속도로는 조정하지 않는다. 반대 손에는 적용하지 않는다.
5. 기존 범위 한도: 펀치 0.28~0.32, 레이즈 0.36~0.40, 블락 0.29~0.32, 이동 0.18~0.22. 몸 크기로 정규화한 값이다.
6. personal_profile.json에 cycle_details와 effective_overrides를 기록한다. 기본값과 같은 측정 결과를 실제 보정 적용이라고 표시하지 않는다. C를 누르면 모두 초기화한다.

확인 결과
이번 Mac 전체 18,088프레임은 기본 v26/수정 전 개인 보정/수정 후 개인 보정의 공격 80회와 상태가 동일했다.
수정 후 오른손 펀치 표본 1→2회, X 표본 0→2회를 수집했다. 일관성이 부족한 오른손 두 표본에는 범위를 억지로 적용하지 않았다.
이번 사람의 범위는 기본값으로 충분해서 effective_overrides는 비어 있다. 이번 실제 기록에서 인식률 상승이 입증됐다는 뜻이 아니다.
합성 좌표에서 두 작은 레이즈 표본 후 이전에 못 잡던 짧은 레이즈를 인식하고, 두 느린 펀치 표본 후 해당 손의 느린 시작을 받아들이는 것을 검증했다.
가장 낮은 새 속도 한도로 기존 여러 사람의 검토된 기록을 재생해 기존 공격·X·후속 공격 보존과 추가 공격 없음 조건을 통과했다. 독립 참가자 정확도 검증은 아니다.
이번 Windows ZIP에는 원본 관절 좌표가 없어서 누락 동작의 전후 재생은 할 수 없었다. 새 export_diagnostics.py --practice-poses로 기존 촬영 중 수련 좌표만 보내면 추가 촬영 없이 분석할 수 있다.

원본 영상/이전 버전은 변경하지 않는다. 새 영상은 기본 MP4 15fps, 인식/관절 기록은 카메라 처리 전체 속도를 유지한다.
